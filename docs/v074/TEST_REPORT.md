## Локальные результаты

- `npm run typecheck`: успешно.
- `npm test -- --reporter=dot --maxWorkers=4`: 27 файлов, 135 тестов успешно. Параллельный запуск тестов и production-сборки вызвал два таймаута старых тестов; отдельный повтор и полный последовательный прогон прошли.
- `npm run build`: успешно.
- Chromium: магазин и кафе на 1280×720 и 800×400, прямые переходы, оформление независимых заказов, отмена заказа магазина, отсутствие `pageerror` и горизонтального выхода за экран.
- Android Emulator API 35 (Pixel 7 Pro): [предрелизный прогон](https://github.com/maxpnz/AZS-Simulator/actions/runs/44284885451) прошёл. Подписанный APK установлен и запущен; сцена и сенсорное открытие меню проверены на 1280×720 и 800×400; снимки просмотрены; в logcat не найдено падений или ANR. Приёмочные снимки сохранены как artifact `android-smoke-31`.
- Локальная установка образов API 24 и 28 не удалась из-за нехватки места на диске; поэтому Android-проверка выполнена в GitHub Actions.

## Ограничения данных

- Старые проводки без `productId` не содержат товар. Экран показывает «—» для неполной детализации вместо ложного количества. Суммы выручки сохранены.
- Оценка сервиса рассчитывается как доля успешных заправок среди завершённых попыток. До первой попытки значение отсутствует; это не пользовательские отзывы.
- Отмена бензовоза доступна до начала подъезда, отмена товаров — до поступления на склад. После физической разгрузки/поставки возврат не выполняется.
