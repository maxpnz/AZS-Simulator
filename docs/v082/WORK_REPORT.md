## Измерения и тесты

- `npm test -- --run`: 37 файлов, 173 теста прошли; `npm run build`: успешно, предупреждение о чанке JS >500 КБ. Альтернативная логика приоритета на выезде провалила регрессионные тесты и была отменена до финального прогона.
- В headless Chromium с программным рендерингом за 12 секунд: до изменений 27 кадров, средний интервал 445,94 мс, p95 566,6 мс; после промежуточных изменений 28 кадров, 447,74 мс, p95 583,4 мс. Такая среда не представляет Android FPS; прирост не подтверждён. Замеры сделаны до последнего кэширования препятствий. Десять нажатий цены в этой среде: 16,75 с на 0.8.1 против 16,85 с на текущем коде; визуальный рендеринг доминирует над сохранением.
- Повторный браузерный прогон с финальными изменениями: 0.8.1 — 15 кадров/12 с, средний интервал 842,37 мс, p95 1083,2 мс, heap 11,32 МБ; текущая ветка — 26 кадров, 466,68 мс, p95 566,6 мс, heap 13,82 МБ. Разброс двух прогонов слишком велик для вывода об улучшении; аппаратные GPU/CPU не измерены.
- 30 игровых суток прошли в симуляционном тесте. Это не 30 минут реального времени.
- Аудиопакет — около 2,72 МБ. Предоставленный OGG: 316,47 с, 2 489 097 байт, декодируется без ошибок. Источники и лицензии: `AUDIO_LICENSES.md`.
- Android SDK, `adb`, локальные переменные подписи и `gh` недоступны в текущей среде; установка/обновление APK и подпись не проверены. GitHub Actions содержит процесс подписи и emulator smoke, но тег запускать нельзя до выполнения ТЗ и тестов. APK, тег и GitHub Release не созданы.
