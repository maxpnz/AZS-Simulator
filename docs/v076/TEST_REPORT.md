# AZS Simulator v0.7.6 — отчёт о проверке

Дата: 19.11.2026. Проверки выполнены локально на исходном коде этого коммита.

## Изменения

- Штатные техники, их найм, обучение, зарплата и авторемонт исключены из работающей модели. Остались три ручных внешних мастера. Старое неоплаченное назначение удаляется при загрузке; старый оплаченный ремонт преобразуется в оплаченный вызов категории «Стандарт» с сохранением остатка времени и без нового платежа. Исторические операции бухгалтерии сохраняются.
- Сохранены десять парковочных мест в два ряда и отдельная зона фур из v0.7.5. Машины длиной больше 4,8 м больше не занимают обычные места. Резервирование старого слота при миграции сохранено, если слот свободен.
- Уведомление о завершении ремонта называет ТРК или резервуар по игровому номеру. Цены магазина и кафе показывают рынок и отклонение. Изменение цены не создаёт всплывающих сообщений.
- Вывески выровнены; шкалы топлива используют зелёный (>50%), жёлтый (>25%), оранжевый (>10%) и красный (0–10%). Исторических порогов в коде не было.

## Известные ограничения

- Для фур предусмотрена одна отдельная зона; при её занятости дополнительные грузовики едут дальше после обслуживания на ТРК.
- Принудительное заполнение всех десяти мест и зоны фур проверено; одновременный выезд всех одиннадцати машин отдельным тестом не моделировался.
- APK не собирался; проверены TypeScript, веб сборка и Chromium. Вывески осмотрены на 1440×900 при двух масштабах, другие размеры покрыты тестами камеры, без ручного визуального осмотра.
