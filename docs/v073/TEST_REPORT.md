# AZS Simulator v0.7.3 — проверка

## Реализация

- Разделённый фасад: существующая геометрия здания и новая прозрачная текстура на основе утверждённого рендера; области магазина и кафе не пересекаются.
- Парковка: четыре места на западном асфальтовом участке у выезда, пути к ним и освобождение после выезда из места. Старые резервации мигрируют; при переполнении автомобиль уезжает по существующему маршруту.
- Магазин и кафе: независимые склады, персонал, продажи и выручка. Нулевые позиции удаляются из корзины до подтверждения. Продажи содержат идентификатор товара; старые проводки без него сохраняются.
- Поставки топлива: ближайшее прибытие вычисляется по минимальному оставшемуся игровому времени активных рейсов. Стела показывает цену с явной десятичной точкой.
- Экраны обзора, конкурентов, разгрузки и ТРК показывают реальные игровые данные. Статистика ТРК строится из журнала операций.

## Автоматические проверки

- `npm run typecheck`
- `npm test -- --reporter=dot --maxWorkers=4`
- `npm run build`
- `ANDROID_HOME=/home/dev/.android-sdk npm run android:apk:debug`
- Подписанная сборка `assembleRelease`; проверка подписи и версии через инструменты Android SDK.
- Chromium: сцена, обзор, конкуренты, магазин, кафе, зона разгрузки, ТРК и окно топлива; отсутствие `pageerror` на проверенных экранах.

Финальный прогон: 26 файлов, 130 тестов прошли. `typecheck`, production build, debug и подписанная release-сборка завершились успешно. APK: `versionCode 22`, `versionName 0.7.3`; `apksigner verify` подтвердил подпись v2. SHA-256: `3f6f45392ddd013c920bec3299cdabb1b4abba5b58ef56fabd19c47ba5655063`. Размеры браузера 1672×941, 1280×720 и 800×400; горизонтального выхода за экран и ошибок `pageerror` не обнаружено. Переходы из левой и правой половин здания проверены кликами по сцене.

## Известные ограничения

- Рейтинг АЗС отсутствует в игровой модели. Верхняя панель явно показывает «— / 5»; фиктивное значение не вводилось.
- Ручная отмена заказа товаров и топлива не поддерживается моделью. После подтверждения заказ завершается доставкой.
- Суточные продажи по товару доступны для операций v0.7.3. Старые проводки без идентификатора товара не распределяются задним числом.
- Магазин и кафе используют общий экран с разными вкладками, запасами и операциями; отдельные визуальные страницы по образцу референсов пока не завершены.
- Физическая приёмка на Android требует устройства или эмулятора; в текущей среде подключённых устройств нет.
