# АЗС Simulator v0.8.4

Диагностический релиз для проверки производительности на устройстве.

- Полностью удалены аудиодвижок, музыка, звуковые эффекты, регуляторы громкости и Android audio focus. Игра работает без звука.
- Автосохранение и сохранение после изменения цен подготавливаются в фоновом Worker. Серия изменений цены сохраняется одной записью. При явном выходе и ручном сохранении запись выполняется сразу.
- Частые записи расходов на освещение и оборудование объединяются по игровым часам; суммы не меняются. При загрузке сохранения v0.8.2 его накопленные записи также объединяются.
- Сохранения v0.8.2 совместимы с v0.8.4.

## Проверка на устройстве

Сравните плавность обычной игры и последовательного изменения цен с v0.8.2. Релиз не меняет маршруты транспорта; ранее известные заторы при десяти ТРК остаются отдельной задачей.
