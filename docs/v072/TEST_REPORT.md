# AZS Simulator 0.7.2 — исправления и проверка

## Почему понадобилась версия 0.7.2

Релиз 0.7.1 перенёс структуру экранов и действия из ТЗ, но использовал преимущественно обычные карточки и старые красные растровые спрайты магазина и навеса. Поэтому визуальное соответствие утверждённым концептам было неполным. Версия 0.7.2 исправляет это, сохраняя игровые правила 0.7.

## Что изменено

- Главное меню: панорама станции и шесть иллюстрированных разделов в сетке 3×2; настройки получили иллюстрацию станции. Магазин и кафе получили общий согласованный арт, но остаются двумя отдельными экранами и показывают фактические товары и остатки даже до открытия здания.
- Техническая служба получила иллюстрацию мастерской; обзор сгруппирован по трафику, обслуживанию и продажам. Для пустого списка резервуаров добавлено понятное состояние с действующей кнопкой строительства.
- Магазин, навес и ТРК на сцене используют новые графитово-зелёные спрайты. Сохранены прежние координаты, размеры объектов, пять опор навеса, десять мест ТРК, дороги и маршруты. Живая вывеска фасада размещена на новом фризе, цифры цен светятся зелёным. Карточки восьми поставщиков используют новый арт бензовоза.
- Заменена иконка веб-приложения и все плотности иконки Android. HUD вновь показывает одну кнопку скорости: 1× → 2× → 4× → 5× → 10× → 1×. Режим 10× уже поддерживался движком; игровая скорость не пересчитывалась.
- Сравнение цен, добавленное в 0.7.1, одинаково работает для рынка и конкурентов: `(наша цена − цена сравнения) / цена сравнения × 100%`. При нулевой, отсутствующей или недоступной цене выводится прочерк. Все показанные цены и показатели берутся из игрового состояния.

## Совместимость и границы изменений

Формат сохранения остался `0.7.0`; файлы симуляции, экономические константы, расчёты продаж, закупок, доставки и ремонта, дорожная сеть и логика движения не изменялись. Существующие тесты проверяют миграцию сохранения 0.6, восстановление 0.7, ручные слоты, поставки, очереди, продажи, ремонт и движение. Ограничения ТЗ, противоречащие работающей версии 0.7, не введены: движок допускает четыре канала ТРК, а улучшение резервуара не требует его опустошения. Последний композитный макет сцены не использовался как утверждённая геометрия.

## Проверки

- `npm run typecheck` — успешно.
- `npm test -- --reporter=dot` — 25 файлов, 125 тестов успешно, включая новый тест цикла скоростей.
- `npm run android:sync` — веб-сборка и синхронизация Android-проекта успешны.
- `./gradlew assembleDebug --no-daemon` — успешно; APK содержит `versionCode=21`, `versionName=0.7.2`.
- Headless Chromium на 1280×720 и 915×412: все шесть разделов меню открывались без ошибок JavaScript и горизонтального переполнения; проверены меню, обзор, цены, поставщики, магазин и кафе, стартовая сцена и цикл скоростей. Снимки находятся в этой папке.
- `git diff --check` — успешно.

Подписанный релизный APK собирается GitHub Actions после отправки тега `v0.7.2`. Проверка на физическом Android-устройстве не проводилась; визуально не проверены все состояния с заполненными складами и ночной сценой.
