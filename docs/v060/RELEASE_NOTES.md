# AZS Simulator v0.6.0

Релиз посвящён технической эксплуатации АЗС. ТРК и резервуары изнашиваются при работе, штатные техники и подрядчики выполняют ремонт, а новый раздел «Техническая служба» показывает назначения и историю. Зарплата, ремонт, найм и обучение отражаются в существующей бухгалтерии. Сохранения 0.5.2 мигрируют автоматически, а видимая игра запрашивает Screen Wake Lock на поддерживаемых устройствах.

Проверка: TypeScript, 113 автоматических тестов, web build и мобильный viewport Chromium. Локальная сборка APK не выполнена из-за отсутствия Android SDK; подписанный APK собирает workflow GitHub при публикации тега. Реальное удержание экрана на физическом устройстве требует ручной проверки.
