# АЗС Simulator — тест v0.2.3

Эта тестовая версия исправляет движение машин по территории АЗС и обновляет графику колонок, стелы и автомобилей. Работы выполнены по ТЗ v1.5 и дополнению `CODEX_GAS_STATION_ROADMAP_0.2.3_PLUS.md`. Следующая версия начнётся только после полной ручной приёмки 0.2.3; замечания могут выпускаться отдельными промежуточными версиями.

## Сценарий и механика

- На старте две обычные колонки и **два резервуара по 2 500 л**: АИ-92 и АИ-95. В каждом первоначально 2 000 л; остаток задан отдельно от вместимости. Оба сорта подключены к обеим колонкам. Другие сорта остаются в справочнике для будущей инфраструктуры и сейчас не продаются.
- Машины заезжают с прилегающей полосы, ждут на обозначенных местах, движутся по асфальту ниже островков и паркуются справа от каждой колонки. После заправки они возвращаются в проезд и выезжают на трассу.
- Выдача топлива зависит от объёма и скорости подачи в игровом времени. Остаток, выданные литры и деньги меняются постепенно; пауза останавливает процесс. Рядом с заправляющейся машиной виден прогресс в литрах.
- В верхней панели показывается текущая очередь. Карточка колонки показывает выданные литры и начисленную сумму; «Обзор» показывает очередь, продажи, выручку и остатки.

Переподключение каналов, поставки, бензовозы и динамические визуальные статусы недоступного топлива запланированы на 0.3–0.4. Строительство и модернизация запланированы на 0.5. Полный отчёт о прибыли пока отсутствует. Изменение цены влияет на сумму продажи, но влияние на спрос появится в 0.4.

## Проверка и сборка

Нужны Node.js 22, Android SDK API 36 и Java 21.

    npm ci
    npm run typecheck
    npm test
    npm run build
    npm run android:sync

Для локальной отладочной сборки: `npm run android:apk:debug`. Тег `v0.2.3` запускает `.github/workflows/android-release.yml`: подписанный APK публикуется в GitHub Releases. Приложение проверяет последний Release и предлагает обновление при наличии новой версии.

Исходная иконка: `assets/app-icon-v02a.png`. Дорожные маршруты описаны в `assets/ROAD_NETWORK_v02a.md` и `src/game/domain/roadNetwork.ts`.
