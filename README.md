# АЗС Simulator v0.2.4

Браузерная игра на React, PixiJS и TypeScript. Игровая сцена собирается из независимых объектов: четырёхполосной трассы, въезда и выезда, здания, навеса, десяти монтажных позиций, ТРК, люков резервуаров и транспорта. Масштаб мира — 20 единиц на метр. На старте установлены две ТРК у первой из пяти опор навеса.

## Механика

- Начальный баланс — 500 000 ₽. Резервуары АИ-92 и АИ-95 вмещают по 2 500 л и содержат по 2 000 л. Цена, закупочная стоимость, остаток и выручка сохраняются отдельно по каждому виду топлива.
- Можно строить ТРК и резервуары, модернизировать их, менять подключённые каналы и заказывать топливо. Работают две строительные бригады; дополнительные работы ждут в очереди. Бензовоз занимает единственную площадку слива и перекачивает топливо по фактическому остатку.
- Машины выбирают полосу, решают о заезде, ждут места, подъезжают к ТРК, заправляются и выезжают. Модели транспорта имеют разные размеры и совместимые виды топлива. Продажи учитываются по фактически выданным миллилитрам.
- Есть пауза, ускорение до 10×, панорамирование и масштабирование сцены, автосохранение в браузере и ручное сохранение/загрузка. Загрузка сохранений v0.2.3 поддерживается.

## Сборка и проверки

Нужны Node.js 22; для Android также Java 21 и Android SDK API 36.

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run android:sync
```

Для отладочного Android APK: `npm run android:apk:debug`. Тег `v0.2.4` запускает `.github/workflows/android-release.yml`; подписанный APK публикуется в GitHub Releases при наличии настроенных секретов подписи.

## Известные ограничения

- Сцена использует программно нарисованные 2D/2.5D объекты. Детализация и свет транспорта пока уступают фотореалистичному стилю из `docs/GRAPHICS_SPEC.md`.
- Полуприцеп и бензовоз пока используют жёсткий габаритный прямоугольник на повороте. Отдельная кинематика прицепа не реализована.
