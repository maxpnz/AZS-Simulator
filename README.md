# АЗС Simulator v0.2.7

Браузерная игра на React, PixiJS и TypeScript. Игровая сцена собирается из независимых объектов: четырёхполосной трассы, въезда и выезда, здания, навеса, десяти монтажных позиций, ТРК, люков резервуаров и транспорта. В v0.2.7 стела показывает все шесть видов топлива одновременно, ТРК получили фронтальный корпус, цветные бирки и крупные номера. Исправлены стороны движения, въезд, выезд и пересечения транспорта. У люков появились цветные маркеры; площадка слива показывает время прибытия и ход разгрузки. Масштаб мира — 20 единиц на метр. На старте установлены две ТРК у первой из пяти опор навеса.

## Механика

- Начальный баланс — 500 000 ₽. Резервуары АИ-92 и АИ-95 вмещают по 2 500 л и содержат по 2 000 л. Цена, закупочная стоимость, остаток и выручка сохраняются отдельно по каждому виду топлива.
- Можно строить ТРК и резервуары, модернизировать их, менять подключённые каналы и заказывать топливо. Работают две строительные бригады; дополнительные работы ждут в очереди. Бензовоз занимает единственную площадку слива и перекачивает топливо по фактическому остатку.
- Машины выбирают полосу, решают о заезде, ждут места, подъезжают к ТРК, заправляются и выезжают. Модели транспорта имеют разные размеры и совместимые виды топлива. Продажи учитываются по фактически выданным миллилитрам.
- Есть пауза, ускорение до 10×, панорамирование и масштабирование сцены от 1× до 3.5×, автосохранение в браузере и ручное сохранение/загрузка. Загрузка сохранений v0.2.3–v0.2.6 поддерживается.

## Сборка и проверки

Нужны Node.js 22; для Android также Java 21 и Android SDK API 36.

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run android:sync
```

Для отладочного Android APK: `npm run android:apk:debug`. Тег `v0.2.7` запускает `.github/workflows/android-release.yml`; подписанный APK публикуется в GitHub Releases при наличии настроенных секретов подписи.

## Известные ограничения

- Транспорт использует отдельные растровые модели в общем ракурсе сверху. На максимальном увеличении 3.5× могут быть заметны пиксели текстур.
- Полуприцеп и бензовоз пока используют жёсткий габаритный прямоугольник на повороте. Отдельная кинематика прицепа не реализована.
