# АЗС Simulator

Текущая версия исходного кода — **v0.5.2**. Графическое обновление и диагностика B01–B19 описаны в [отчёте](docs/v052/BUG_REPORT.md), набор спрайтов — в [спецификации](docs/v052/ASSETS.md). Релизные файлы публикуются по тегу через GitHub Actions. Актуальные игровые правила, экономика и критерии проверки находятся в [своде правил](docs/GAME_RULES-2.md).

Стек: TypeScript, React, PixiJS, Vite и Capacitor. Требуется Node.js 22; для локальной Android-сборки также Java 21 и Android SDK API 36.

Команды:

- Установка: `npm ci`
- Запуск браузерной версии: `npm run dev`
- Проверка типов и тесты: `npm run typecheck`; `npm test`
- Веб-сборка: `npm run build`
- Синхронизация Android-проекта: `npm run android:sync`
- Отладочный APK при установленном SDK: `npm run android:apk:debug`

В v0.5.0 появились девять независимых конкурентов с графиком цен и перебоями, поставщик «НефтеОпт» с объёмными скидками, полноценные запросы на заправку с атомарным резервированием, карточки машин и этапы обслуживания водителем. Грузовики и фуры могут обслуживаться на подходящих ТРК; у стелы сохраняется последняя цена при отсутствии топлива, а дисплей ТРК хранит итог последнего клиента. Сохранения v0.4 мигрируют автоматически, исходная копия остаётся в локальном хранилище до успешной записи новой версии.

В v0.5.1 машины выбирают ТРК до въезда: ожидание происходит на размеченном месте конкретной колонки, общий затор на въезде устранён. Сообщение «Большая очередь» появляется только при шести ожидающих. На основной дороге по две полосы в каждую сторону, между направлениями газон; полосы разделены прерывистой линией. Убраны персонажи и их маршруты, исправлен вид бензовоза и выезд тяжёлого транспорта. Конкуренты не продают топливо дешевле текущей базовой закупочной цены. Сохранения 0.4 и 0.5 загружаются с переносом ожидающих машин к ТРК; исходное сохранение 0.5 копируется перед первой записью новой версии.

Полноэкранные разделы автоматически приостанавливают игровое время. Карточка автомобиля не останавливает симуляцию. Сохранение выполняется автоматически. Управление камерой: перетаскивание, колесо мыши или жест двумя пальцами.

Подписанные APK и веб-архивы доступны в [GitHub Releases](https://github.com/maxpnz/AZS-Simulator/releases). Для обновления старых APK v0.2.8 и v0.3.0 до исправленной проверки обновлений v0.3.1 требовалась однократная ручная установка; дальнейшие версии используют автоматическую проверку.
