# АЗС Simulator — тест v0.2.2

Версия 0.2.2 реализует подэтап v0.2-B по ТЗ v1.5: трассовый трафик на четырёх полосах, заезд на АЗС, очередь, обслуживание у двух ТРК и базовые продажи из стартового запаса. Предыдущая сцена, камера и меню v0.2-A сохранены. Версия v0.2 в целом ожидает ручной приёмки.

## Что проверить

- Автомобили едут в обоих направлениях по четырём полосам. На АЗС поворачивают только с прилегающей полосы, проходят через въезд, очередь и ТРК и возвращаются через отдельный выезд.
- Встречаются легковые машины, фургоны и грузовики, разные сорта топлива. Грузовики используют ДТ. При занятой колонке машины ждут и иногда уезжают.
- Продажи уменьшают остаток соответствующего сорта и увеличивают деньги. В меню «Обзор» видны трафик, продажи, выручка и последние чеки.
- Цены и состав топлива ТРК настраиваются через интерактивные объекты. Новая цена фиксируется при назначении машины к ТРК; занятую ТРК перенастроить нельзя.
- Пауза и скорости 1× → 2× → 5× → 10× работают, камера не показывает пустое пространство.

Закупки, поставки, расходы, ценовая эластичность, сохранения текущей сессии и полный отчёт о прибыли запланированы в следующих этапах. Стартовый запас уже оплачен и не списывается повторно. Игра показывает текущие продажи и условную себестоимость отдельно.

## Сборка

Нужны Node.js 22, Android SDK API 36 и Java 21.

    npm ci
    npm run typecheck
    npm test
    npm run build
    npm run android:sync

Для локальной отладочной сборки: `npm run android:apk:debug`.

Тег `v0.2.2` запускает `.github/workflows/android-release.yml`. Workflow собирает подписанный APK с прежним `applicationId` и ключом и публикует его в GitHub Releases. Приложение проверяет последний Release и предлагает обновление при появлении версии с большим номером.

Исходная иконка: `assets/app-icon-v02a.png`. Полная спецификация: `AZS_Simulator_Economy_Design_v1.5.md`.
