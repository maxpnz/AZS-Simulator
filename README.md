# АЗС Simulator

Текущая версия кода — **v0.3.2**; статус публикации см. в [истории изменений](CHANGELOG.md). Ручная приёмка игроком ожидается. Последняя принятая игроком версия — **v0.2.8**. Требования к игре, состояние объектов, экономика и известные дефекты собраны в [своде правил](docs/GAME_RULES-2.md). При разработке игровых функций обновляйте его вместе с кодом.

Стек: TypeScript, React, PixiJS, Vite и Capacitor. Требуется Node.js 22; для локальной Android-сборки также Java 21 и Android SDK API 36.

Команды:

- Установка: npm ci
- Запуск браузерной версии: npm run dev
- Проверка типов и тесты: npm run typecheck; npm test
- Веб-сборка: npm run build
- Синхронизация Android-проекта: npm run android:sync
- Отладочный APK при установленном SDK: npm run android:apk:debug

Подписанный APK v0.3.1 доступен в [GitHub Releases](https://github.com/maxpnz/AZS-Simulator/releases/tag/v0.3.1). В v0.2.8 и v0.3.0 автоматическая проверка обновления не работала в опубликованных APK: для перехода на v0.3.1 скачайте и установите APK вручную поверх игры. Сохранение останется на устройстве. Начиная с v0.3.1 игра проверяет обновления при запуске.

В v0.3.2 баланс открывает раздел «Финансы АЗС», а меню содержит Обзор, Цены и Настройки. Все полноэкранные разделы и скрытие вкладки автоматически приостанавливают игровое время. Сохранение происходит автоматически.
