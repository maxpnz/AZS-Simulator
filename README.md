# АЗС Simulator — UX-тест v0.2.1

В этой подписанной тестовой версии реализован только подэтап v0.2-A по ТЗ v1.5: обновлённые интерфейс, камера и игровая сцена. Автомобили, продажи и поставки не запущены. Переход к v0.2-B требует ручной приёмки UX.

## Проверка

- Верхнее меню содержит разделы прежней боковой и нижней панелей.
- Время управляется паузой и одной циклической кнопкой скорости 1× → 2× → 5× → 10×.
- Стела, обе колонки и резервуары открывают карточки. Настройки в них демонстрационные.
- На сцене показаны четыре полосы трассы, отдельные въезд и выезд. Маршрутные узлы описаны в assets/ROAD_NETWORK_v02a.md.
- Камера ограничена границами нарисованного мира.

## Сборка

Нужны Node.js 22, Android SDK API 36 и Java 21.

    npm ci
    npm run typecheck
    npm test
    npm run android:sync

Для локальной отладочной сборки: npm run android:apk:debug.

Тег v0.2.1 запускает .github/workflows/android-release.yml. Workflow собирает подписанный APK с тем же applicationId и ключом, что у v0.1.1, затем публикует его в GitHub Releases. Приложение проверяет последний Release и предлагает обновление при появлении версии с большим номером. Для следующих тестовых сборок увеличивайте версию 0.2.2, 0.2.3 и так далее, а также Android versionCode.

Исходная иконка: assets/app-icon-v02a.png. Полная спецификация: AZS_Simulator_Economy_Design_v1.5.md.
